Why consult the Codex

Mid-combat, it's easy to default to "just attack" every round, even when defending, repositioning, or disengaging is the wiser play. The Codex weighs the same four choices the same way, every round, so the tradeoffs are visible instead of automatic. This one's also here to show a different kind of build than the other two tools in the same portfolio: the same deterministic-scoring, AI-narrates philosophy, applied somewhere with room for personality.

How the Codex is different
